# Blinkit_Sales_Analysis-(PowerBI Project)
# 📌 Project Overview
This Project Focuses on Analysing Blinkit(grocery delivery) sales data to understand business performance, customer purchase behavior, and product level insights.
The analysis was conducted using Power BI, where raw data was transformed, modeled, and visualized into an interactive dashboard to support strategic decision-making.

# 🎯 Objectives
● Analyze overall sales performance and revenue trends

● Identify top-performing product categories and items

● Understand customer purchasing patterns

● Evaluate the impact of product attributes (fat content, category, etc.)

● Provide actionable insights for business growth

# 🧰 Tools & Skills Used
● Power BI

● Data Modeling

● DAX (Data Analysis Expressions)

● Data Cleaning & Transformation (Power Query)

● Dashboard Design & Visualization

● KPI Development

# 📂 Dataset Description

The dataset contains sales and product-level information, including:

Item Fat Content

Item Identifier

Item Type

Outlet Establishment Year

Outlet Identifier

Outlet Location Type

Outlet Size

Outlet Type

Item Visibility

Item Weight

Sales 

Rating


# 📊 Key Analysis Performed
► Total Sales and Average Sales

► Sales by Item Type and Category

► Outlet-wise Performance Analysis

► Impact of Outlet Size and Location on Sales

► Customer Rating Analysis
